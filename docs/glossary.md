# Glossary

- **Managed Space**: Logical governed container owned by a principal.
- **Global Contract**: Non-overridable rules for section/operation shape.
- **Space Manifest**: Space definition including sections and metadata.
- **Space Gateway**: Only entry point to read/write space resources.
- **Space Resolver**: Maps public alias to internal space ID.
- **Local Policy**: Space-owned policy rules.
- **Local Index**: Claim-oriented lookup index.
- **Resource Envelope**: Signed/trusted logical wrapper for stored resources.
- **Write-Only Inbox**: Deposit endpoint with no depositor read/list.
- **Identity Claim**: Verified claims in JWT identity token.
- **Canonical Object**: Single object representation reused by references.
- **Outbox Reference**: Sender-side reference to canonical object.
- **Inbox Reference**: Receiver-side reference stored in write-only inbox.
