# Security Policy

OpenMSA follows a responsible disclosure model.

If you suspect a vulnerability:

- Do not post details in public issues.
- Email `security-contact@example.com` (placeholder).
- Include impact details, reproduction steps, and severity clues.

For this repository, reports may target:

- authentication/authorization bypass
- token signing or validation issues
- policy evaluation bypass
- path traversal, SQL injection, or storage access abuse
- disclosure of raw resource paths
