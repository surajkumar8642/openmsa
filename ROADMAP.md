# Roadmap

## Completed

- .NET 9 modular solution with identity, policy, index, storage, gateway, and example API.
- Asymmetric JWT issuance and verification.
- Local SQLite index and filesystem storage adapters.
- Declarative policy evaluation with default deny.
- Write-only inbox behavior and generic not-found style responses.

## In progress

- Rich JSON schema validation package for manifests and policies.
- More complete CLI/SDK tooling.
- Additional audit backends and observability hooks.

- Public SDK samples for multi-language clients.

## Future

- Optional remote index and object storage adapters
- Real key lifecycle & rotation notifications
- Formal admin audit and abuse detection workflows
